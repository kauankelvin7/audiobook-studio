# Code review checklist

- [ ] Mudança corresponde ao objetivo do TASK PACKET.
- [ ] Não há API, teste ou resultado inventado.
- [ ] Entradas de PDF/LLM são tratadas como não confiáveis.
- [ ] Erros são tipados e não descartados silenciosamente.
- [ ] Estado, retries e idempotência foram considerados.
- [ ] Testes e quality gates disponíveis foram executados.
- [ ] Acessibilidade e navegação por teclado não regrediram.
- [ ] Dependências e licenças foram revisadas.
- [ ] WORKLOG e ADRs foram atualizados quando necessário.
